# Objective Partner v2.0 — «Объективный собеседник»

Скилл для независимой проверки аргументов и решений. Помогает отделять факты от интерпретаций, проверять предпосылки, признавать сильные доводы и пересматривать выводы при новых данных. Не требует спорить ради спора и не превращает каждый вопрос в длинный аудит.

## Установка

Скопируйте папку `objective-partner` целиком в каталог скиллов вашего агента — см. [инструкцию установки](../README.md#установка-в-codex). Для Codex доступно явное обращение `$objective-partner`. Скилл не зависит от дневника, Python или внешнего подключения.

При ручном использовании попросите агента прочитать [SKILL.md](SKILL.md) и применять его к текущему обсуждению. Это не включает правила во всех будущих чатах автоматически. Доступ к прошлой переписке и источникам определяется возможностями конкретного агента.

## Команды

| Команда | Что получится |
|---|---|
| `Используй $objective-partner` | Прямой ответ с проверкой существенных допущений без обязательного служебного формата |
| `Эпистемический режим` | Разделение известных данных, выводов, альтернатив и неопределённости |
| `Проверь дрейф` | Поиск роста уверенности и превращения гипотез в факты в доступной истории |
| `Проверь резюме беседы` | Сверка конспекта с доступными исходными репликами и исправление искажений |

## Примеры

```text
Используй $objective-partner. Вот мой план: [...].
Проверь ключевые предпосылки, существенные слабые места и условия успеха.
```

```text
Эпистемический режим. Какие из этих выводов следуют из данных,
а какие пока являются только возможными объяснениями?
```

```text
Проверь резюме беседы. В исходнике написано «возможно»,
а в конспекте — «установлено». Исправь только неподтверждённые усиления.
```

Для краткого ответа прямо укажите желаемую длину. Если пользователь прав, ожидается обоснованное согласие. Если появляются новые доказательства, ожидается пересмотр прежней позиции. Настойчивость сама по себе не считается новым свидетельством.

## Ограничения

Скилл не гарантирует истинность вывода без достаточных данных, не открывает закрытые документы и не заменяет проверку актуальных сведений. Не устанавливает Claude PreCompact hook или другие runtime-хуки: проверка конспекта выполняется по запросу и по доступному контексту. Никакие личные данные, предпочтения конкретного владельца или ключи для запуска не нужны.

## Версия и происхождение

Это публичная редакция восстановленной версии **2.0**. Оригинальный файл не использовался для побайтовой сверки, поэтому версия не заявляется точной архивной копией. В публичном комплекте удалены привязки к личной переписке; сохранены правила и команды восстановленной версии.

Идеи: независимая оценка из anti-sycophancy, прямой язык Frank и аккуратность Claude Epistemic Mode. Это собственное изложение принципов; чужие полные инструкции в комплект не включены. Ссылки на источники идей — в [уведомлениях](../THIRD_PARTY_NOTICES.md).
