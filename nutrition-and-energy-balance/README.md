# Питание и энергобаланс

Модуль комплекса [дневника](../maintain-nutrition-training-diary/README.md): оценка неизвестной порции, КБЖУ, разбор рациона, расхода и целей питания. Личные параметры берёт из внешнего профиля текущего пользователя. Записи и изменение целей выполняются через основной скилл.

Устанавливается рядом с остальными папками по [общей инструкции](../README.md#установка-в-codex). Дневник подключает модуль по необходимости; отдельно можно вызвать `$nutrition-and-energy-balance` для разбора предоставленных данных. Самостоятельный вызов не создаёт дневник и не даёт права изменять его.

Примеры: «Оцени порцию по фото и укажи диапазон», «Разбери рацион по моему дневнику», «Сравни потребление и расход с учётом покрытия данных». Отсутствующие сведения не считаются нулём. Расход за часть дня и прогноз за сутки показываются раздельно.

Справочники: [оценка пищи](references/food-estimation.md), [энергобаланс](references/energy-and-goals.md). Для внешних научных оснований используется [scientific-source-verification](../scientific-source-verification/SKILL.md). Происхождение и лицензии — в [уведомлениях](../THIRD_PARTY_NOTICES.md).
