# Проверка научных источников

Модуль для проверки существования публикации, её метаданных и того, поддерживает ли она конкретное утверждение. Применяется к значимым внешним основаниям рекомендаций. Разрешающийся DOI сам по себе не доказывает вывод, качество исследования или применимость к человеку.

Установка — по [общей инструкции](../README.md#установка-в-codex). Пример: «Используй $scientific-source-verification: проверь эти ссылки и основания вывода». Нужны доступные первоисточники; ограничение по абстракту явно отмечается.

## Необязательный скрипт

Python 3.10+, только стандартная библиотека; сеть к Crossref/OpenAlex/arXiv по режиму проверки. Запуск из корня репозитория:

```sh
python scientific-source-verification/scripts/verify_citations.py --help
python scientific-source-verification/scripts/verify_citations.py --doi 10.1038/nature14539
python scientific-source-verification/scripts/verify_citations.py references.bib --json report.json
```

Передавайте только публичную библиографию. Не отправляйте дневник, медицинскую историю или приватные документы. `CROSSREF_MAILTO` — необязательная настройка окружения с контактным адресом, который будет передан Crossref; не добавляйте свой адрес в код репозитория.

Коды выхода: `0` — библиографическая проверка пройдена или найдены недостающие DOI; `1` — найдены проблемы; `2` — ошибка входа. Сравнение названий в этой версии ориентировано на ASCII: кириллицу и другие письменности проверяйте вручную. Скрипт не читает исследование за агента и не проверяет медицинскую рекомендацию.
