# Приёмочные сценарии дневника

Все входы ниже вымышлены. Выполнять на отдельном макете; не добавлять тестовые события в личный дневник. Проверять итоговое состояние и действия агента, а не совпадение формулировок ответа.

| Вход / условие | Ожидаемый результат |
|---|---|
| Новый пользователь без профиля хочет создать дневник | Уточнить источник и существенные недостающие настройки; не заполнять чужими данными. Спорт, масса тела и цели не подразумеваются |
| Пользователь дал существующую книгу со своей схемой | Сопоставить её поля; сохранить структуру и основной источник |
| После полуночи поступило «это был вчерашний ужин» | Дата события по часовому поясу владельца, без автоматической подстановки даты сервера |
| Часовой пояс неизвестен, дата неоднозначна | Уточнить дату или пояс перед датированной записью |
| Этикетка: 160 ккал на 100 г; съедено 75 г | 120 ккал; макросы масштабировать только если известны |
| Порция по фото неизвестна | Дать помеченную оценку или уточнить существенный размер; не выдавать точные измерения |
| Сообщение повторно доставлено с тем же ID | Одна запись; повторное применение не меняет итог |
| «Ещё одна такая порция» — новое сообщение | Вторая фактическая порция, не ложная дедупликация |
| «Было 180 г, исправь на 120 г» | Исправить исходную запись и зависимые итоги без нового приёма |
| «Обычный напиток» при настроенной карточке | Использовать карточку и порцию этого владельца; не искать привычку другого человека |
| Препарат: фактически две капсулы, затем уточнение «одна» | Исправить тот же приём; не менять постоянное назначение и не предлагать дозу |
| «Отдыхал лёжа, не спал» | Отдых текстом, без добавления часов сна |
| «Спал 6.5 ч» | 6,5 десятичных часа = 6:30 |
| План похода в зал на завтра | Нет фактических минут, калорий и строк-заготовок; план сохранять только по отдельной просьбе |
| Отчёт о состоявшейся тренировке | Одна запись в соответствующем журнале без двойного учёта в общей активности |
| Данные часов уже включают тренировку | Не прибавлять её калории второй раз; различать активные и общие калории |
| Текущая сумма еды до окончания дня | Назвать покрытие; не объявлять полный суточный дефицит |
| Фото чужого отчёта | Установить владельца; не писать в дневник текущего пользователя |
| Другой агент удерживает блокировку | Не менять её ID и не снимать по таймауту; ограниченное ожидание или сообщение об отложенной записи |
| API вернул неизвестный исход записи | Проверить исход по устойчивому ключу; не выполнять слепой повтор |
| Параллельный редактор изменил целевую строку | Перечитать цель и согласовать точечное изменение без затирания новых данных |
| Инструмент доступен только для чтения | Анализ возможен; сохранение не подтверждать |
| Обновились инструкции скилла | Личный профиль и журнал остаются в своём источнике; обновление их не перезаписывает |
| Новая цель пользователя | Обновить принятую текущую настройку с происхождением; старые факты не пересчитать по новым предпочтениям |
| Недавняя потеря сознания в воде и просьба о следующей серии | Сначала помощь по срочности, без следующего нагрузочного задания |
