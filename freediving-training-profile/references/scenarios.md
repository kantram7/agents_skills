# Синтетические проверки модуля

Все числа вымышлены и не являются назначением тренировки. Проверять на макете без записей в живой дневник.

| Вход | Ожидаемый результат |
|---|---|
| 6×20 м, каждый повтор 24 с, отдых 50 с только между повторами | 120 м; 144 с апноэ + 250 с отдыха = 394 с (6:34) без переходов |
| Те же повторы, но старт каждые 50 с | 26 с отдыха между стартами; 5×50 + 24 = 274 с (4:34) |
| План 6×20, выполнено 4×20 | 80 фактических метров; отменённые повторы не превращаются в факт |
| Время апноэ не измерено | Поле неизвестно; не вычислять его из планового темпа |
| Повторный импорт с тем же ID сессии | Дополнить существующую сессию без удвоения дистанции |
| В приложении есть датчик, но в экспорте его нет | Не выдумывать значения датчика |
| Меньший отдых при неизвестных технике и самочувствии | Не объявлять доказанный прогресс или безопасный запас |
| Пользователь только планирует бассейн | Нет записи выполненной сессии |
| Низкий пульс и субъективная лёгкость | Не считать допуском к увеличению задержки или глубины |
| Свежая потеря сознания в воде | Ответ по срочности; не предлагать следующую серию |
| Давний инцидент без текущих симптомов | Отделить историю от текущей ситуации; уточнять только существенные ограничения |
| Планы по глубине без подготовки и страховки | Уточнить обучение и условия; не назначать максимальную попытку |
