# Фридайвинг и апноэ v1

Модуль [дневника](../maintain-nutrition-training-diary/README.md) для анализа сессий, техники, повторяемости, серий, пауз и восстановления. Поддерживает разбор сухой практики, бассейна и глубины с учётом конкретной подготовки и условий пользователя.

Устанавливается рядом с остальными папками по [общей инструкции](../README.md#установка-в-codex). Пример: «Используй $freediving-training-profile. Сравни эти две выполненные сессии: [...]». Планирование требует собственных исходных данных пользователя; синтетические примеры не являются готовыми тренировками.

Сначала настраиваются применимые дисциплины, недавняя практика, обучение, условия страховки и существенные ограничения. Эти сведения хранятся во внешнем профиле, не в универсальных инструкциях. Ведение журнала остаётся за основным скиллом.

Скилл не подключает Freediver.club, STAmina, часы или датчики. Используются только подтверждённые интеграции или предоставленный экспорт. Низкий пульс, субъективная лёгкость и таймер не служат допуском к продолжению апноэ. Водное апноэ требует подготовленной активной страховки; острый инцидент не проверяется следующей нагрузкой.

Справочники: [модель сессии](references/session-model.md), [планирование](references/planning.md), [безопасность и датчики](references/safety-and-sensors.md), [источники](references/sources.md). [Сценарии](references/scenarios.md) выполняются на макете, без личного дневника.
